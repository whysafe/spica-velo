# Спица: сайт веломастерской с калькулятором ремонта

Одностраничный сайт веломастерской, на котором клиент сам собирает список работ, сразу видит цену и срок, считает зимнее хранение и записывается на удобный день. Мастерской меньше звонков «а сколько стоит», клиенту — понятная квитанция до визита.

## Возможности

**Калькулятор ремонта**
- 15 работ в четырёх группах: колёса, тормоза, трансмиссия, подшипники и вилка
- Пять типов велосипеда с коэффициентом цены: городской, MTB, шоссе/гревел, детский, электро; цены округляются до 50 ₽
- Автоподстановка «Комплексного ТО»: если отмеченные работы по отдельности дороже пакета, они сворачиваются в него, и квитанция показывает экономию
- Срочный ремонт +30% и срок по нормо-часам: «при вас», «на следующий день», «сегодня до закрытия» или «N–N+1 дня»
- Выбор запоминается в `localStorage` и переживает перезагрузку

**Сезонное хранение**
- Ползунок срока от 1 до 8 месяцев, отдельный тариф для электровелосипедов
- Скидка 10% с 4 месяцев и 20% с 6, цена за месяц и сумма без скидки

**Запись**
- Работы и сумма подтягиваются из калькулятора
- Проверка имени, мобильного номера (8, +7 или без кода, со скобками и дефисами) и даты: не в прошлом, не дальше 30 дней, не в понедельник
- Ошибки у полей с `aria-invalid`, фокус на первом неверном поле, после отправки — номер квитанции

**Оформление**
- Своя палитра «бумага, чернила, сигнальный оранжевый» и пара шрифтов Dela Gothic One + Geologica
- Велосипед нарисован в SVG, колёса крутятся при прокрутке страницы (выключается при `prefers-reduced-motion`)
- Квитанция с перфорацией через CSS-маску, адаптивная вёрстка от 360 px

## Запуск

ES-модули не открываются через `file://`, нужен любой статический сервер:

```bash
git clone https://github.com/whysafe/spica-velo.git
cd spica-velo
npx serve .
```

Или `python -m http.server 8000`. На Windows Python иногда берёт MIME-тип `.js` из реестра как `text/plain`, и браузер не загружает модуль; тогда используйте `npx serve`.

## Как устроено

- `js/estimate.js` — прайс, коэффициенты и расчёты: `estimate()` для ремонта и `storagePrice()` для хранения. Чистые функции без DOM.
- `js/booking.js` — нормализация телефона, проверка заявки и номер квитанции. «Сегодня» передаётся параметром, поэтому проверки дат детерминированы в тестах.
- `js/app.js` — отрисовка формы из данных прайса, квитанция, ползунок хранения и отправка заявки. Чтобы поменять цены или добавить работу, достаточно отредактировать `WORK_GROUPS`.

Заявка не уходит на сервер: это демо. Для реальной мастерской обработчик `onBookingSubmit` отправляет данные в Telegram-бота или CRM.

## Тесты

```bash
npm test
```

15 тестов: коэффициенты и округление, подстановка комплексного ТО и расчёт экономии, срочность и сроки, дубликаты и неизвестные работы, скидки на хранение, форматы телефона, даты (прошлое, понедельник, 30 дней, 30 февраля), номер квитанции. В CI тесты и проверка синтаксиса скриптов запускаются на каждый push.
